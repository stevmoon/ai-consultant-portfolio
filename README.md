# AI Consulting & Automation Portfolio

Production-ready enterprise AI systems, deterministic financial underwriting engines, and multi-agent architectures.

---

## Core Systems & Deliverables

### 1. Automated Commercial Real Estate & Equity Underwriting Engine
* **Tech Stack:** Python, Pandas, yFinance, Matplotlib
* **Core Capabilities:**
  - Automated multi-asset portfolio valuation and dynamic return tracking.
  - Institutional technical trend analysis (50-Day vs. 200-Day Simple Moving Averages).
  - Deterministic Cap Rate, NOI, and Debt Service Coverage Ratio (DSCR) underwriting hurdles with zero LLM hallucination risk.

### 2. Intelligent Travel Reservation Intake Microservice
* **Tech Stack:** Google GenAI SDK (Gemini Flash), Native Structured JSON Mode, Python
* **Core Capabilities:**
  - Converts unstructured, messy Spanish WhatsApp audio/text requests into strict, validated JSON objects in < 2 seconds.
  - Automated extraction of Member IDs, destination, pax counts, and budget parameters.
  - Programmatic calculation of projected gross booking margins and SLA tracking.

---

## Architecture Principles
* **Deterministic Guardrails:** Never allowing probabilistic language models to perform arithmetic; all calculations are executed via verified Python tools.
* **Hybrid Architecture:** Deterministic No-Code Spines (Make.com/n8n) for ingestion and CRM routing + Modular AI Agents for cognitive synthesis.
